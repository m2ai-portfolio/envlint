   - check_git_tracking_safe() - Web-safe version with exception handling
   - Uses subprocess with 5-second timeout for all git commands
   - Returns comprehensive status dictionary

2. ✅ Updated envlint/main.py (CLI)
   - Added --no-git-check flag to skip git check
   - Git check runs by default
   - Displays colored status messages:
     * Red error if .env is tracked (security risk)
     * Green success if .env is properly ignored
     * Cyan info if not in git repo

3. ✅ Updated envlint/web.py (Web API)
   - Added check_git parameter to /validate endpoint
   - Returns git_status in response when enabled
   - Adds error if .env is tracked

4. ✅ Updated envlint/templates/index.html (Web UI)
   - Added "Check git tracking" checkbox (default: checked)
   - Displays git status with color coding:
     * Red box if tracked (bad)
     * Green box if ignored (good)
     * Gray box if not in repo
